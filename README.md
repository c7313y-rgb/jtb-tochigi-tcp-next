# JTB Tochigi TCP / NEXT High School proposal

公開ページ: https://c7313y-rgb.github.io/jtb-tochigi-tcp-next/

栃木県教育委員会・採択校向けの企画提案説明LPです。提案者は株式会社JTB。県の公式募集サイトではありません。2026年10月10日時点の提案情報と県の公開RFI資料をもとに構成しています。

## 内容
- JTBの教育事業の資産と実施価値
- 副担任mirAI NEXTの生徒・先生・学校向け活用イメージ
- 農業・工業・理数・多様な学びの授業例
- 各社の役割案、25か月の実施計画、評価・引継ぎ
- 30秒のコンセプト動画（オリジナル音楽、日本語字幕）

## 更新
静的HTML/CSS/JavaScriptです。`index.html`、`styles.css`、`app.js`と`assets/`を更新してください。GitHub Pagesはmainブランチのルートを公開します。

- 連携打診中の各社、未確定の提供条件はその旨を明示しています。

- mirAI NEXTのUIは架空の学習例に基づくデモで、実製品画面ではありません。
