# JTB Tochigi TCP / NEXT High School proposal

公開ページ: https://c7313y-rgb.github.io/jtb-tochigi-tcp-next/

栃木県教育委員会・採択校向けの企画提案説明LPです。提案者は株式会社JTB。県の公式募集サイトではありません。2026年10月10日時点の提案情報と県の公開RFI資料をもとに構成しています。

## 内容
- JTBの教育事業の資産と実施価値
- 副担任mirAI NEXTの生徒・先生・学校向け活用イメージ
- 農業・工業・理数・多様な学びの授業例
- 各社の役割案、25か月の実施計画、評価・引継ぎ
- 30秒のコンセプト動画（オリジナル音楽、日本語字幕）

## 更新
静的HTML/CSS/JavaScriptです。`index.html`、`styles.css`、`app.js`と`assets/`を更新してください。GitHub Pagesはmainブランチのルートを公開します。

## 表示と情報の扱い
- 連携打診中の各社、未確定の提供条件はその旨を明示しています。
- 写真・イラストは本提案用のAI生成イメージで、実際の学校・実績写真ではありません。
- mirAI NEXTのUIは架空の学習例に基づくデモで、実製品画面ではありません。
- 公開版に担当者個人の連絡先、内部の参考積算、原資料ファイルは含めていません。
- お問い合わせはJTBの公開済み公式教育窓口へリンクしています。
- アクセス解析・外部フォント・Cookie・入力フォームは実装していません。


## 2026-10-10 調達要件マップ反映
- 仕様書の2業務（プロデュース／コーディネート）に整合
- R8成果の引継ぎ、R9→R10の判定基準、全県立学校への展開
- 4校の構想別支援、宇都宮工業の学科再編・企業実習
- KPI・自走の数値はJTBの協議前提案値として明示
- 一括／分割の責任範囲、8成果物、権利・データ移管、全経費・5年保存
- 前回の審査基準・追加採択・資格適合は確定扱いしない

公開RFI仕様書: https://www.pref.tochigi.lg.jp/m04/documents/20260911110232.pdf
